# Практическая работа № 1. Открытые API, парсинг HTML и регулярные выражения

### Цель работы

Освоить получение и первичную обработку данных из открытых интернет-источников и научиться превращать собранные данные в обоснованные аналитические выводы.

### В ходе работы необходимо

* получить данные через открытый **REST API** с учётом пагинации, ограничений и обработки ошибок;
* выполнить парсинг HTML-страниц с помощью **BeautifulSoup** и **XPath**;
* очистить и нормализовать текстовые данные с использованием **регулярных выражений (RegEx)**;
* сформировать итоговые таблицы в `pandas`;
* провести разведочный анализ данных (**EDA**) и построить визуализации;
* сформулировать выводы и практические рекомендации на основе рассчитанных показателей.

### Инструменты

`Python` · `Google Colab` · `requests` · `BeautifulSoup4` · `lxml` · `re` · `pandas` · `NumPy` · `Matplotlib` · `Seaborn`

### Выполнение работы

Работа выполняется в Google Colab по индивидуальному варианту **1–30**. Необходимо последовательно выполнить задания, отмеченные `TODO`, и запустить встроенную самопроверку.

Минимальный объём данных:

* не менее **50 записей из API**;
* не менее **40 объектов**, полученных парсингом сайта.

При сборе данных необходимо соблюдать правила этичного использования интернет-ресурсов: учитывать ограничения источника, использовать паузы и кэширование, не публиковать API-ключи, токены и персональные данные.

### Результат

Выполненный `.ipynb`-ноутбук должен содержать код, результаты выполнения ячеек, визуализации, рассчитанные показатели и итоговые аналитические выводы.
