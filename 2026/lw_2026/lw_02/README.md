# Лабораторная работа № 2. Консолидация разнородных источников: CSV, Excel, JSON → SQLite → аналитика

### Цель работы

Освоить полный цикл консолидации данных из нескольких источников: от загрузки и аудита качества до построения реляционной модели, расчёта аналитических показателей и формирования управленческих выводов.

### В ходе работы необходимо

* объединить данные из **CSV, Excel и JSON**;
* провести аудит качества по критериям полноты, уникальности, согласованности, валидности, целостности и точности;
* выполнить очистку данных с ведением **журнала изменений** и карантина ошибочных записей;
* определить кардинальность связей между таблицами;
* изучить эффект **fan-out** при соединениях `1:N`;
* создать реляционную базу **SQLite** с первичными и внешними ключами, ограничениями и индексами;
* рассчитать выручку средствами **SQL** и проверить результат в `pandas`;
* выполнить ABC/Парето-анализ, анализ сезонности и структуры выручки;
* сформулировать выводы и рекомендации для лица, принимающего решения.

### Инструменты

`Python` · `Google Colab` · `pandas` · `NumPy` · `CSV` · `Excel` · `JSON` · `SQLite` · `SQL` · `Matplotlib`

### Выполнение работы

Работа выполняется по индивидуальному варианту **1–30**. Номер варианта определяет предметную область, объём данных и набор намеренно внесённых дефектов.

Основной конвейер:

**источники → аудит качества → очистка → SQLite → SQL-анализ → визуализация → выводы**

Особое внимание необходимо уделить корректности соединения таблиц. Наивный `JOIN` таблиц со связью `1:N` может привести к многократному завышению рассчитанной выручки.

Раздел **BigQuery** является дополнительным и позволяет повторить построение аналитической витрины в облачном хранилище.
