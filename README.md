## Как выполнять работу

1. Сначала откройте **задание на EnvLab** и ознакомьтесь с вариантом и критериями.
2. Скачайте соответствующий файл из каталога `2027/`; выполняйте задания `TODO` самостоятельно.
3. Запустите работу, сохраните результаты и объяснения; убедитесь в воспроизводимости.
4. Загрузите результат в свой репозиторий и сдайте **ссылку через EnvLab**. Не публикуйте токены, пароли, персональные данные и ключи Kaggle.

**При расхождении описаний приоритет имеют актуальные требования и сроки задания на EnvLab.**
