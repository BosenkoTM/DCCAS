# Программные средства сбора, консолидации и аналитики данных

Курс посвящён современным программным средствам работы с данными: от их получения из веб-источников и консолидации разнородных наборов до аналитики, визуализации и применения генеративного искусственного интеллекта.

> **Основная версия курса полностью представлена на образовательном портале [EnvLab](https://envlab.ru/).**
> На EnvLab размещаются лекционные материалы, задания, литература, сроки выполнения работ и другие учебные активности.

Материалы текущего учебного года в GitHub: **[2026](2026/)**.

## Темы курса

### Тема 1. Программные средства сбора данных

Рассматриваются основные технологии получения данных из интернет-источников:

* REST API;
* HTML и XML;
* регулярные выражения;
* BeautifulSoup и XPath;
* статический и динамический веб-парсинг;
* Playwright и Selenium;
* правила безопасного и этичного сбора данных.

Практическая часть включает получение, очистку, преобразование и первичный анализ данных.

### Тема 2. Программные средства консолидации данных

Изучается объединение данных из различных источников и подготовка единого набора данных для дальнейшей аналитики:

* CSV, Excel и JSON;
* `pandas`;
* очистка и контроль качества данных;
* ETL/ELT;
* SQLite и SQL;
* связи между таблицами и корректное выполнение `JOIN`;
* автоматизация конвейеров обработки данных.

### Тема 3. Программные средства аналитики данных

Тема посвящена преобразованию подготовленных данных в аналитическую информацию для поддержки принятия решений:

* разведочный анализ данных;
* ключевые показатели и метрики;
* визуализация;
* аналитические витрины;
* интерактивные дашборды;
* интерпретация результатов анализа.

Итогом практической работы является разработка **аналитического дашборда для бизнес-кейса**.

### Тема 4. Интеллектуальные средства анализа данных (GenAI)

Рассматриваются современные подходы к использованию генеративного искусственного интеллекта в задачах анализа данных:

* применение LLM в аналитическом процессе;
* интеллектуальная обработка и интерпретация данных;
* генерация аналитических запросов;
* автоматизация отдельных этапов анализа;
* проверка и критическая оценка результатов, полученных с помощью GenAI.
