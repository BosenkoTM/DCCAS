#  Программные средства сбора, консолидации и аналитики данных**

Этот репозиторий содержит материалы курса, посвященного полному циклу работы с данными: от их извлечения из различных источников до создания интерактивных аналитических дашбордов. Курс охватывает современные инструменты и подходы, включая использование AI-ассистентов для ускорения разработки.

## **Структура курса**

### **Лекция 1. Программные средства сбора данных: от API до веб-парсинга**

Первая лекция посвящена методам сбора данных из веб-источников. Рассматриваются как основы работы с API, так и техники веб-скрапинга с использованием Python.

**Ключевые темы:**
*   Основные методы сбора данных: API и веб-скрапинг.
*   Этические и юридические аспекты (`robots.txt`, условия использования).
*   Форматы данных: HTML и XML, структура DOM-дерева.
*   Извлечение информации с помощью регулярных выражений в Python.
*   Парсинг HTML с использованием библиотеки `BeautifulSoup`.
*   Применение AI-ассистентов (Cursor, Copilot) для генерации кода парсеров и API-запросов.

### **Лекция 2. Программные средства консолидации и очистки данных**

Вторая лекция фокусируется на процессе ETL/ELT. Студенты учатся объединять данные из разрозненных источников, очищать их и подготавливать для анализа, а также автоматизировать эти процессы.

**Ключевые темы:**
*   Концепция ETL (Extract, Transform, Load) и создание "единого источника правды".
*   Очистка, интеграция и форматирование данных.
*   Использование библиотеки `Pandas` для манипуляции данными.
*   Data-centric AI: автоматический поиск ошибок в данных с помощью `Cleanlab`.
*   Оркестрация конвейеров данных с помощью `Apache Airflow` (DAG, Operator, Task).
*   Роль AI в генерации кода для трансформации данных и в low-code/no-code платформах.

### **Лекция 3. Программные средства аналитики данных: интерактивные дашборды с Apache Superset**

Заключительная лекция посвящена Business Intelligence (BI) и визуализации данных. На примере open-source платформы `Apache Superset` рассматривается полный цикл создания интерактивных дашбордов.

**Ключевые темы:**
*   Введение в Business Intelligence и роль визуализации в принятии решений.
*   Обзор возможностей и архитектуры `Apache Superset`.
*   Полный флоу работы: подключение к данным, исследование в SQL Lab, создание чартов и дашбордов.
*   Добавление интерактивности: фильтры и кросс-фильтрация.
*   Использование AI-ассистентов для ускорения аналитики: Text-to-SQL и генерация идей для визуализаций.
*   Симбиоз аналитика и AI в BI-задачах.
