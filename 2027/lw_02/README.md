# ЛР № 2. Консолидация разнородных источников

**Задание и критерии:** [EnvLab № 424](https://envlab.ru/mod/assign/view.php?id=424).  
**Ноутбук:** [`ЛБ2_Консолидация_CSV_Excel_JSON_SQLite_студент.ipynb`](ЛБ2_Консолидация_CSV_Excel_JSON_SQLite_студент.ipynb).  
**Среда:** Google Colab, pandas, NumPy, SQLite и SQL. **Оценка:** 10 баллов (+ до 2 за дополнительное задание).

## Сквозной процесс

`CSV + Excel + JSON → контроль качества → очистка + карантин + журнал → SQLite → SQL + pandas → витрина → ABC/Парето и сезонность → решения`

### Обязательные проверки
- Полнота, уникальность, допустимость значений, согласованность и ссылочная целостность.
- Данные с ошибками не удаляются молча — фиксируются в журнале или карантине.
- При связи `1:N` обычный `JOIN` может завысить выручку: стоимость события агрегируется до объединения с его объёмом.
- Результаты SQL сверяются с расчётами pandas.
- На основе рейтинга, структуры выручки и сезонности обосновываются управленческие рекомендации.

Исходные данные для 30 вариантов генерируются в ноутбуке; отдельные CSV/XLSX/JSON выкладывать для старта не требуется. Файлы с результатами студент создаёт при выполнении. Задание по BigQuery — дополнительное, если предусмотрено актуальным текстом на EnvLab.
