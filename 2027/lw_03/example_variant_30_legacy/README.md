# Иллюстративный проект — вариант 30 (архивный код)

Здесь сохранены только **программные файлы и открытый учебный набор данных** из ранее опубликованного демонстрационного проекта `lpw_04`:

- `us_presidents_dag.py` — демонстрационная последовательность извлечения, загрузки и преобразования данных;
- `datamart_variant_30.sql` — учебная SQL-витрина;
- `us_presidents.csv` — входные данные примера.

**Это не эталонное решение 2027 года.** DAG использует интерфейсы Airflow 2.x (`PythonOperator` и `PostgresOperator` в старых путях импорта), поэтому **не запускайте файл в Airflow 3.x без адаптации**. В проекте остаются вопросы воспроизводимости и реальной доступности Kaggle; пример предназначен для **разбора архитектуры** и показывает лишь один вариант.

Исходный Docker Compose из архивного проекта в новую сборку намеренно не перенесён: он основан на устаревшем PostgreSQL 12, Airflow 2.5 и локальных демонстрационных паролях. Файлы `kaggle.json`, `.kaggle/`, логи и потенциальные секреты **не включены**.

Актуальная постановка, баллы и требования: [EnvLab № 427](https://envlab.ru/mod/assign/view.php?id=427).
