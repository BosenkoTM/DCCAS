# ЛР № 4. Интеллектуальные средства анализа (GenAI)

**Тема:** RAG-ассистент службы поддержки — построение, измерение рисков и оценка экономического эффекта.  
**Задание:** [EnvLab № 423](https://envlab.ru/mod/assign/view.php?id=423).  
**Файл:** [`lab_04_genai_student.ipynb`](lab_04_genai_student.ipynb).  
**Среда:** Google Colab, без обязательного Docker, внешней СУБД и платного API.  
**Максимум:** 10 баллов + до 2 за дополнительное задание.

## Бизнес-задача
Рассмотрите решение руководства о внедрении RAG-ассистента для обработки примерно 20 000 обращений первой линии поддержки ежемесячно. Требуется установить долю корректно закрываемых обращений, вероятность ошибок и отказов, риски утечек/промпт-инъекций, чувствительность экономики внедрения.

## Ход выполнения
1. Выберите вариант (1–30); сгенерируйте воспроизводимый учебный корпус.
2. Изучите качество корпуса, выполните `TODO 1–11`.
3. Сравните методы поиска (`Recall@k`, `MRR`), влияние разбиения и контекста.
4. Отдельно проверьте **обоснованность и правильность** ответа — это разные показатели.
5. Измерьте отказ, галлюцинации, обработку ПДн и защиту от инъекций.
6. Рассчитайте стоимость решения в рублях, выполните индивидуальный эксперимент и сформулируйте решение о внедрении с ограничениями.

Основной режим генерации **`template`** — намеренно детерминированный, чтобы изолировать влияние поиска и промпта. Это не доказательство качества реальной LLM и не замена испытаний с моделью. `local`/`api` — только для дополнительного эксперимента, с учётом правил обращения с ключами.

Форма сдачи: выполненный студентом ноутбук с таблицами, графиками, экспериментами, выводами и ссылкой через EnvLab. **Преподавательское эталонное решение не включено в открытый каталог.**
