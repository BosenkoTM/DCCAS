# ЛР № 1. Современный парсинг динамических веб-сайтов

**Задание:** [EnvLab № 418](https://envlab.ru/mod/assign/view.php?id=418).  
**Оценка:** 10 баллов. **Среда:** Google Colab; Playwright, Selenium, Chromium, XPath, lxml, pandas.

## Файлы

- [`ЛР1_Playwright_Selenium_динамический_парсинг_студент.ipynb`](ЛР1_Playwright_Selenium_динамический_парсинг_студент.ipynb) — студенческие задания для вариантов 1–30.
- [`market_stand.html`](market_stand.html) — локальный учебный JS-стенд с искусственными данными, задержкой рендеринга, cookie-баннером и догрузкой строк.

## Выполнение
1. Откройте основной ноутбук, задайте свой вариант.
2. Используйте учебный стенд для управления браузером и загрузки данных. Обратите внимание на параметризуемый адрес `market_stand.html?variant=НОМЕР&profile=ПРОФИЛЬ`; точные параметры определяются ноутбуком.
3. Разберите HTML, нормализуйте цены, проценты, пропуски и суффиксы объёма.
4. Сравните Playwright с Selenium, покажите результаты обработки и сделайте выводы.
5. Сохраните ноутбук, полученный Excel и скриншот; ссылку на репозиторий сдайте через EnvLab.

Страница `market_stand.html` должна обслуживаться локальным HTTP-сервером: её нельзя считать живым источником рыночных цен. Все данные стенда **учебные, синтетические**.

**Безопасность:** не обходите CAPTCHA/Cloudflare и авторизацию; соблюдайте правила сайтов и не собирайте ПДн.
