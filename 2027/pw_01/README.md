# ПР № 1. Открытые API, парсинг HTML и регулярные выражения

**Тема:** программные средства сбора данных.  
**Задание и сдача:** [EnvLab № 415](https://envlab.ru/mod/assign/view.php?id=415).  
**Файл:** [`ПР1_API_парсинг_RegEx_студент.ipynb`](ПР1_API_парсинг_RegEx_студент.ipynb).  
**Среда:** Google Colab / Python. **Максимум:** 10 баллов.

## Содержание
Получение записей из открытого REST API с пагинацией и корректной обработкой ошибок; HTML-парсинг с BeautifulSoup и XPath; нормализация данных регулярными выражениями; подготовка таблиц pandas, EDA, графиков и управленческих выводов. Минимально — 50 записей API и 40 HTML-объектов (см. ноутбук и EnvLab).

## Последовательность
1. Откройте notebook в Google Colab; задайте номер своего варианта (1–30).
2. Читайте блоки теории и выполните задания `TODO`, не изменяя выданные варианты.
3. Проверьте корректность выгрузки, дубликаты, пропуски, единицы измерения, данные графиков.
4. Сохраните ноутбук с выводами и результатами, опубликуйте в личном репозитории и предоставьте ссылку через EnvLab.

**Необходимо:** соблюдать условия API/сайта, ограничения запросов и требования к персональным данным. API-ключи хранить вне репозитория (Colab Secrets).
